- Color palette: ONLY white and blue as background colors. Use pure white (#FFFFFF) and professional blues (e.g., #003366, #0055A4, #1E90FF, soft light blue #E6F0FA for sections). - Clean, modern, student-friendly UI with plenty of white space. Minimal text — focus on short, punchy key points, bold headlines, and scannable bullets that attract students. Do not remove important content, just present it concisely and attractively.
- Responsive design (mobile-first, works perfectly on phone, tablet, desktop).
- Smooth subtle animations (fade-ins, hover effects) but keep it professional and lightweight.
